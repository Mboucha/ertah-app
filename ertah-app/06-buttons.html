00 · Anatomy
Button Anatomy
Every button is built from three optional slots: a leading icon, a label, and a trailing icon — within a pressable container that respects variant, size, shape, and direction.

Leading icon
Label
Trailing icon

Container
Pressable Container
Sets height, horizontal padding, background, border, border-radius. Applies scale(0.97) on press via Reanimated spring.
Label
Text Label
Uses typography.label.lg/md/sm. Color is derived from variant + color prop. Always single-line, never wraps.
Leading icon
Left Icon (start side)
Appears on the start side — right in RTL, left in LTR. Gap to label: 8px. Inherits label color.
Trailing icon
Right Icon (end side)
Appears on the end side — left in RTL, right in LTR. Same gap and color rules as leading icon.
Loading
ActivityIndicator
Replaces all content with a spinner. Dimensions unchanged. Color matches label color. FadeIn/FadeOut 150ms.
